# HWRun OS Linux — 设计笔记

> 研究/设计中。以下为待你确认的方向，不是定稿。

## 目标

在宿主应用里提供一个极简、隔离、可跑的 Linux 环境，用于：
- 隔离沙盒（跑不可信代码）
- 本地开发 / 工具箱
- 插件运行环境

## 关键问题

1. **发行版选型**：极简（Alpine + busybox + musl？），能装软件、能跑程序。
2. **承载层**：各宿主 OS 如何让这个 Linux 跑起来（Windows / macOS / Linux / 安卓）。
   每 OS 一个承载层、共享同一环境定义（参考 Docker Desktop / Lima / Termux 思路）。
3. **许可边界**：内核与承载层若用 GPL，作为独立仓库分发，不传染宽松许可的主产品
   （边界 = 不链进主程序、独立进程调用）。
