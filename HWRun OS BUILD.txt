HWRun OS BUILD 实现文档

模块名称： BUILD (Build System)
版本： 1.0.0
状态： 设计冻结
定位： 构建系统，负责将 HWRun OS 源码编译成可运行的操作系统镜像
依赖工具： GNU Make, GCC, NASM, debootstrap, live-build, dpkg-buildpackage, reprepro
输出产物： 内核镜像 (.bin/.ko)、用户态插件 (.so)、APT 仓库、可启动 ISO

一、设计哲学

1.1 核心定位

BUILD 是 HWRun OS 的“制造工厂”——将所有源码编译、打包、组装成可启动的操作系统镜像。

```
BUILD = 构建系统 = 将源码转化为可运行系统的完整工具链

源码仓库
    │
    ▼
BUILD 系统
    ├── 阶段 1: 编译微内核 (kernel.bin)
    ├── 阶段 2: 编译内核模块 (HAP, PMP, FSP, NP, SP, LOADER, CLUSTER, INSTANCE, ...)
    ├── 阶段 3: 编译用户态插件 (BUS, PARAM, LOG, GIT, UI, SHELL, DESKTOP, ...)
    ├── 阶段 4: 构建 Debian 基础系统 (debootstrap)
    ├── 阶段 5: 组装可启动 ISO (live-build)
    └── 阶段 6: 生成 APT 仓库 (reprepro)
    │
    ▼
输出产物
├── kernel.bin                 ← 微内核 (ELF64)
├── *.ko                        ← 内核模块 (HAP, PMP, FSP, NP, SP, ...)
├── *.so                        ← 用户态插件 (BUS, PARAM, LOG, ...)
├── hwrun-os-amd64.iso          ← 可启动 ISO
└── APT 仓库                    ← 软件包仓库
```

1.2 设计原则

1. 分层构建：从底层到上层逐层构建，每层产物作为下一层的输入
2. 可重现：相同源码 + 相同环境 → 相同二进制
3. 模块化：每个插件独立构建，可单独编译、测试、打包
4. 容器化：构建环境封装在 Docker 容器中，保证环境一致性
5. 自动化：全流程一键构建，支持 CI/CD

1.3 构建工具链

工具 用途 说明
GNU Make 构建流程控制 顶层 Makefile 驱动整个构建
GCC 编译 C 代码 用户态插件和部分内核模块
x86_64-elf-gcc 编译微内核 交叉编译工具链
NASM 汇编 Legacy BIOS 引导加载器
GNU EFI UEFI 开发库 UEFI 引导加载器
debootstrap Debian 基础系统 创建最小 Debian rootfs
live-build ISO 构建 生成可启动 ISO
dpkg-buildpackage Debian 打包 生成 .deb 包
reprepro APT 仓库管理 管理私有软件源

三、核心构建脚本

3.1 顶层 Makefile

```makefile
# Makefile — HWRun OS 顶层构建文件

.PHONY: all clean distclean install build-env \
        kernel modules plugins bootloader debian iso repo

VERSION := $(shell cat VERSION)
BUILD_DIR := $(shell pwd)/build
OUT_DIR := $(BUILD_DIR)/out

all: kernel modules plugins bootloader debian iso repo

# ============================================================
# 构建环境
# ============================================================
build-env:
	@echo "==> Setting up build environment..."
	@mkdir -p $(BUILD_DIR)/out
	@docker build -t hwrun-builder -f $(BUILD_DIR)/env/Dockerfile .

# ============================================================
# Stage 1: 微内核
# ============================================================
kernel: $(OUT_DIR)/kernel/kernel.bin

$(OUT_DIR)/kernel/kernel.bin:
	@echo "==> Building microkernel..."
	@mkdir -p $(OUT_DIR)/kernel
	$(MAKE) -C kernel -j$(shell nproc)
	@cp kernel/kernel.bin $(OUT_DIR)/kernel/

# ============================================================
# Stage 2: 内核模块
# ============================================================
modules: $(OUT_DIR)/modules/hap.ko $(OUT_DIR)/modules/pmp.ko \
         $(OUT_DIR)/modules/fsp.ko $(OUT_DIR)/modules/np.ko \
         $(OUT_DIR)/modules/sp.ko $(OUT_DIR)/modules/loader.ko \
         $(OUT_DIR)/modules/cluster.ko $(OUT_DIR)/modules/instance.ko

$(OUT_DIR)/modules/%.ko:
	@echo "==> Building kernel module: $*"
	@mkdir -p $(OUT_DIR)/modules
	$(MAKE) -C plugins/$* -j$(shell nproc)
	@cp plugins/$*/$*.ko $(OUT_DIR)/modules/

# ============================================================
# Stage 3: 用户态插件
# ============================================================
plugins: $(OUT_DIR)/plugins/metaproto.so $(OUT_DIR)/plugins/bus.so \
         $(OUT_DIR)/plugins/param.so $(OUT_DIR)/plugins/log.so \
         $(OUT_DIR)/plugins/git.so $(OUT_DIR)/plugins/ui.so \
         $(OUT_DIR)/plugins/shell.so $(OUT_DIR)/plugins/desktop.so \
         $(OUT_DIR)/plugins/pkgmgr.so $(OUT_DIR)/plugins/monitor.so \
         $(OUT_DIR)/plugins/sandbox.so

$(OUT_DIR)/plugins/%.so:
	@echo "==> Building plugin: $*"
	@mkdir -p $(OUT_DIR)/plugins
	$(MAKE) -C plugins/$* -j$(shell nproc)
	@cp plugins/$*/$*.so $(OUT_DIR)/plugins/

# ============================================================
# Stage 4: 引导加载器
# ============================================================
bootloader: $(OUT_DIR)/bootloader/BOOTX64.EFI $(OUT_DIR)/bootloader/boot.bin

$(OUT_DIR)/bootloader/BOOTX64.EFI:
	@echo "==> Building UEFI bootloader..."
	@mkdir -p $(OUT_DIR)/bootloader
	$(MAKE) -C bootloader/uefi -j$(shell nproc)
	@cp bootloader/uefi/BOOTX64.EFI $(OUT_DIR)/bootloader/

$(OUT_DIR)/bootloader/boot.bin:
	@echo "==> Building Legacy BIOS bootloader..."
	@mkdir -p $(OUT_DIR)/bootloader
	$(MAKE) -C bootloader/legacy
	@cp bootloader/legacy/boot.bin $(OUT_DIR)/bootloader/

# ============================================================
# Stage 5: Debian 包打包
# ============================================================
debian: $(OUT_DIR)/debian/linux-image-hwrun_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-bus_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-param_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-log_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-git_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-ui_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-shell_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-desktop_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-pkgmgr_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-monitor_$(VERSION)_amd64.deb \
        $(OUT_DIR)/debian/hwrun-sandbox_$(VERSION)_amd64.deb

$(OUT_DIR)/debian/%.deb:
	@echo "==> Building Debian package: $*"
	@mkdir -p $(OUT_DIR)/debian
	@# 对于每个组件，调用 dpkg-buildpackage
	@cd debian/$* && dpkg-buildpackage -us -uc -b
	@mv debian/*.deb $(OUT_DIR)/debian/

# ============================================================
# Stage 6: ISO 构建
# ============================================================
iso: $(OUT_DIR)/iso/hwrun-os-amd64.hybrid.iso

$(OUT_DIR)/iso/hwrun-os-amd64.hybrid.iso:
	@echo "==> Building ISO..."
	@mkdir -p $(OUT_DIR)/iso
	@cd iso && ./build-iso.sh $(OUT_DIR)

# ============================================================
# Stage 7: APT 仓库
# ============================================================
repo:
	@echo "==> Generating APT repository..."
	@cd repo && ./build-repo.sh $(OUT_DIR)/debian

# ============================================================
# 清理
# ============================================================
clean:
	@echo "==> Cleaning build artifacts..."
	@rm -rf $(OUT_DIR)
	@$(MAKE) -C kernel clean 2>/dev/null || true
	@for d in plugins/*; do $(MAKE) -C $$d clean 2>/dev/null || true; done
	@$(MAKE) -C bootloader/uefi clean 2>/dev/null || true
	@$(MAKE) -C bootloader/legacy clean 2>/dev/null || true

distclean: clean
	@echo "==> Deep cleaning..."
	@rm -rf $(BUILD_DIR)
	@rm -rf repo/pool repo/dists

install:
	@echo "==> Installing build artifacts..."
	@cp -r $(OUT_DIR)/* /usr/local/hwrun/
```

3.3 内核模块通用 Makefile 模板

```makefile
# plugins/<module>/Makefile

obj-m := $(MODULE_NAME).o

# 多文件模块
$(MODULE_NAME)-objs := $(MODULE_NAME)_main.o $(MODULE_NAME)_sub.o

KERNEL_DIR ?= /lib/modules/$(shell uname -r)/build
PWD := $(shell pwd)

all:
	$(MAKE) -C $(KERNEL_DIR) M=$(PWD) modules

clean:
	$(MAKE) -C $(KERNEL_DIR) M=$(PWD) clean

install:
	install -D -m 644 $(MODULE_NAME).ko /usr/lib/hwrun/plugins/
```

3.4 用户态插件通用 Makefile 模板

```makefile
# plugins/<plugin>/Makefile

CC = gcc
CFLAGS = -fPIC -Wall -Wextra -O2 -Iinclude
LDFLAGS = -shared

TARGET = $(PLUGIN_NAME).so
OBJS = $(PLUGIN_NAME).o $(PLUGIN_NAME)_sub.o

all: $(TARGET)

$(TARGET): $(OBJS)
	$(CC) $(LDFLAGS) -o $@ $^

%.o: %.c
	$(CC) $(CFLAGS) -c -o $@ $<

clean:
	rm -f $(OBJS) $(TARGET)

install:
	install -D -m 644 $(TARGET) /usr/lib/hwrun/plugins/
```

    --bootloaders "syslinux,grub-efi" \

5.2 仓库构建脚本

```bash
#!/bin/bash
# repo/build-repo.sh

set -e

DEB_DIR="$1"
REPO_DIR="$(pwd)/repo"

echo "==> Building APT repository..."

# 1. 创建 GPG 密钥（如果不存在）
if [ ! -f "$REPO_DIR/repo.key" ]; then
    gpg --batch --gen-key <<EOF
%no-protection
Key-Type: RSA
Key-Length: 4096
Subkey-Type: RSA
Subkey-Length: 4096
Name-Real: HWRun OS Repository
Name-Email: repo@hwrun.org
Expire-Date: 0
EOF
    gpg --armor --export repo@hwrun.org > "$REPO_DIR/repo.key"
fi

# 2. 添加 .deb 包到仓库
for deb in "$DEB_DIR"/*.deb; do
    echo "Adding: $(basename $deb)"
    reprepro -b "$REPO_DIR" includedeb bookworm "$deb"
done

# 3. 生成仓库元数据
reprepro -b "$REPO_DIR" export bookworm

echo "==> APT repository built: $REPO_DIR"
```

```yaml
# .github/workflows/build.yml

name: Build HWRun OS

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]
  release:
    types: [ published ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
      
      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3
      
      - name: Build builder image
        run: docker build -t hwrun-builder -f build/env/Dockerfile .
      
      - name: Build HWRun OS
        run: |
          docker run --rm \
            -v $(pwd):/build \
            -w /build \
            hwrun-builder \
            make -j$(nproc) all
      
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: hwrun-os
          path: |
            build/out/iso/*.iso
            build/out/debian/*.deb
      
      - name: Upload to release
        if: github.event_name == 'release'
        uses: softprops/action-gh-release@v1
        with:
          files: |
            build/out/iso/*.iso
            build/out/debian/*.deb
```

七、构建命令

```bash
# 完整构建
make all

# 只构建特定阶段
make kernel          # 只构建微内核
make modules         # 只构建内核模块
make plugins         # 只构建用户态插件
make bootloader      # 只构建引导加载器
make debian          # 只构建 Debian 包
make iso             # 只构建 ISO
make repo            # 只构建 APT 仓库

# 清理
make clean           # 清理构建产物
make distclean       # 深度清理

# 在 Docker 容器中构建
docker run --rm -v $(pwd):/build -w /build hwrun-builder make all

# 交叉编译 (ARM64)
make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- all
```

八、总结

维度 决策
构建工具 GNU Make + Docker
微内核 x86_64-elf-gcc 交叉编译
内核模块 Linux kbuild 系统
用户态插件 GCC 编译为 .so
引导加载器 NASM (Legacy) + GNU EFI (UEFI)
基础系统 debootstrap (Debian 12)
打包格式 .deb (dpkg-buildpackage)
ISO 构建 live-build
APT 仓库 reprepro
CI/CD GitHub Actions
产物大小 ISO ~200-500MB

BUILD 是 HWRun OS 的构建系统，将分散的源码（微内核、内核模块、用户态插件、引导加载器）编译、打包、组装成可启动的操作系统镜像。构建流程分为 8 个阶段，从微内核到 ISO 逐层构建，最终输出可启动 ISO 和 APT 仓库。整个构建过程可通过 Makefile 一键完成，也支持分阶段构建和 CI/CD 自动化。
