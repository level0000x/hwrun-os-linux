# HWRun OS Linux

独立项目：一个**极简的 Linux 运行层 / 发行版**，用于在应用里提供隔离的 Linux 环境
（沙盒 / 开发 / 插件运行）。

> 本仓库与 `new-community`（宽松许可主产品）**独立分发**。运行层可按需含 GPL 内核/承载层
> （GPL 传染仅约束本仓库自身，不进入宽松许可的主产品——主产品只以独立进程/接口调用本层）。

## 定位

- **极简**：不是完整桌面发行版，是一个能启动、能装软件、能跑命令/程序的最小 Linux 环境。
- **跨系统承载**：不同宿主 OS 各维持一个「承载层」（Windows / macOS / Linux / 安卓），共享同一套环境定义。
- **用途**：隔离沙盒 / 本地开发环境 / 插件运行环境。
