二、SANDBOX 实现文档

2.1 设计定位

SANDBOX = 轻量级安全隔离执行环境

用于运行不受信任的代码，提供进程级隔离（namespace + seccomp-bpf）。

```
SANDBOX 与 INSTANCE 的区别：
├── INSTANCE：完整操作系统实例（容器/MicroVM/VM），重隔离，适合长期运行
└── SANDBOX：轻量级沙盒，进程级隔离，适合短期运行不受信任的代码
```

技术方案： 基于 nsjail或 gVisor的轻量级封装。

四、SHELL 实现文档

4.1 设计定位

SHELL = 命令行解释器

接收用户命令并执行。

```
SHELL 工作流程[reference:7]：
┌─────────────────────────────────────────────────────────────────────────────┐
│  无限循环: 读取 → 解析 → 执行 → 反馈                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│  1. 读取: 显示提示符，读取用户输入                                          │
│  2. 解析: 解析命令和参数                                                   │
```

```c
// shell/src/shell.c

/* SHELL 主循环 */
void shell_main_loop(void) {
    char line[1024];
    
    while (1) {
        // 1. 显示提示符
        shell_print_prompt();
        
        // 2. 读取输入
        if (!shell_read_line(line, sizeof(line))) {
            continue;
        }
        
        // 3. 解析命令
        char *args[64];
        int argc = shell_parse(line, args);
        
        if (argc == 0) continue;
        
        // 4. 执行命令
        if (shell_is_builtin(args[0])) {
            shell_execute_builtin(argc, args);
        } else {
            shell_execute_external(argc, args);
        }
        
        // 5. 记录历史
        shell_add_history(line);
    }
}

/* 执行外部命令 */
int shell_execute_external(int argc, char **argv) {
    pid_t pid = fork();
    
    if (pid == 0) {
        // 子进程：执行命令[reference:9]
        execvp(argv[0], argv);
        exit(1);
    } else {
        // 父进程：等待子进程结束[reference:10]
        int status;
        waitpid(pid, &status, 0);
        return WEXITSTATUS(status);
    }
}
```

MONITOR = 系统监控

提供系统指标采集、告警、历史查询功能。

8.2 核心数据结构

```c
// monitor/include/monitor.h

typedef struct metric_sample {
    uint64_t timestamp;
    double value;
    struct metric_sample *next;
} metric_sample_t;

typedef struct metric {
    char name[64];
    char unit[16];
    char type[32];                  // gauge / counter / histogram
    metric_sample_t *samples;
    int sample_count;
    double min, max, avg;
    struct metric *next;
} metric_t;

typedef struct alert_rule {
    char id[64];
    char metric[64];
    char operator[8];               // ">", "<", "=="
    double threshold;
    int duration;                   // 持续时间（秒）
    char severity[16];              // info / warn / error / critical
    int enabled;
    struct alert_rule *next;
} alert_rule_t;
```

8.3 协议定义

```protobuf
// protocols/monitor.proto
service Monitor {
    rpc GetMetrics(GetMetricsRequest) returns (GetMetricsResponse);
    rpc GetAlerts(GetAlertsRequest) returns (GetAlertsResponse);
    rpc SetAlert(SetAlertRequest) returns (SetAlertResponse);
    rpc ClearAlert(ClearAlertRequest) returns (ClearAlertResponse);
    rpc GetHistory(GetHistoryRequest) returns (GetHistoryResponse);
    rpc Subscribe(SubscribeRequest) returns (SubscribeResponse);
    rpc Unsubscribe(UnsubscribeRequest) returns (UnsubscribeResponse);
    rpc GetThresholds(Empty) returns (GetThresholdsResponse);
}

message Metric {
    string name = 1;
    string unit = 2;
    string type = 3;
    double value = 4;
    uint64 timestamp = 5;
}

message Alert {
    string id = 1;
    string metric = 2;
    string message = 3;
    string severity = 4;
    uint64 triggered_at = 5;
    bool acknowledged = 6;
}

message GetMetricsResponse {
    repeated Metric metrics = 1;
    int32 error = 2;
}
```

8.4 插件描述文件

```yaml
# plugins/monitor/plugin.yml
plugin:
  id: "monitor"
  name: "System Monitor"
  version: "1.0.0"
  type: "application"
  description: "系统监控"
  provides:
    - protocol: "MONITOR"
      version: "1.0"
  requires:
    - protocol: "LOG"
    - protocol: "PARAM"
    - protocol: "HAP"
    - protocol: "PMP"
    - protocol: "FSP"
    - protocol: "NP"
    - protocol: "CLUSTER"
  params:
    - key: "monitor.interval"
      default: 5                     # 采集间隔（秒）
    - key: "monitor.retention_days"
      default: 7                     # 数据保留天数
    - key: "monitor.max_samples"
      default: 10000                 # 最大采样数
```

九、总结

插件 定位 依赖 代码量
SANDBOX 轻量级安全隔离 PMP, FSP, SP ~800 行
UI 用户界面 INPUT, DISPLAY ~1200 行
SHELL 命令行解释器 PMP, FSP, LOADER ~1000 行
CONSOLE 系统控制台 INPUT, DISPLAY ~600 行
DESKTOP 桌面环境 UI, FSP, SHELL ~1500 行
PKGMGR 包管理 FSP, NP, GIT, LOADER ~1200 行
MONITOR 系统监控 HAP, PMP, FSP, NP, CLUSTER ~1000 行

这七个上层应用插件共同构成了 HWRun OS 的用户可见功能层。它们通过底层协议（HAP、PMP、FSP、NP、SP、INSTANCE、CLUSTER 等）访问系统资源，通过上层协议（UI、SHELL、DESKTOP 等）提供用户交互，形成一个完整的、可用的操作系统用户体验。
